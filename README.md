# Tunisia Drought Early Warning System

## Project Introduction

The **Tunisia Drought Early Warning System** is an interactive web-based mapping application designed to provide a geographic visualization of Tunisia's governorates.

The project uses an interactive map to display the boundaries of Tunisian governorates and allows users to select individual governorates to view their available geographic and attribute information.

The system provides a foundation for developing a more comprehensive drought monitoring and early warning platform by combining geographic data with environmental and climatic information.

## Project Objectives

The main objectives of the project are:

* To develop an interactive map of Tunisia's governorates.
* To visualize governorate-level geographic information.
* To allow users to interact with and select individual governorates.
* To display available attribute information for each governorate.
* To provide a geographic foundation for a future drought monitoring system.
* To support the integration of environmental and climatic data for drought assessment.
* To create a simple and accessible interface for exploring geographic information related to Tunisia.

## Data Used

The project uses an **ESRI Shapefile** containing the geographic boundaries and attribute information of Tunisia's governorates.

The Shapefile consists of four main components:

| File              | Description                                                         |
| ----------------- | ------------------------------------------------------------------- |
| `Tunisia_gov.shp` | Contains the geographic shapes of the governorates                  |
| `Tunisia_gov.shx` | Contains the spatial index of the Shapefile                         |
| `Tunisia_gov.dbf` | Contains the attribute information associated with the governorates |
| `Tunisia_gov.prj` | Contains the coordinate reference system information                |

The geographic data is hosted in a GitHub repository and retrieved by the web application.

The project also uses **OpenStreetMap** as the base map to provide geographic context.

## Conclusion

The **Tunisia Drought Early Warning System** provides an interactive geographic platform for exploring Tunisia's governorates and their associated information.

The current system establishes the mapping component required for a larger drought early warning platform. It can be further developed by integrating environmental and climatic indicators such as vegetation indices, rainfall, temperature, and other drought-related variables.

The project therefore provides a foundation for developing an interactive and data-driven system capable of supporting drought monitoring and early warning activities in Tunisia.
