Tunisia Vegetation Web Map

← Back to Home

This is an interactive web map designed to provide a geographic visualization of Tunisia's vegetation.

The project uses an interactive map to display the boundaries of Tunisian governorates and allows users to select individual governorates to view their available geographic and attribute information.

The system provides a foundation for developing a more comprehensive drought monitoring and early warning platform by combining geographic data with environmental and climatic information.

Objectives

  • To visualize governorate-level vegetation information.
  • To allow users to interact with and select individual governorates.
  • To display available attributes for each governorate.

Data Used

Vegetation and Environmental Data

Tunisia's vegetation data: tunisia_ndvi.csv

Source (edited): tunisia_drought_latest.csv

Main indicators include NDVI, NDVI anomaly, Rainfall, VCI, VHI and other environmental variables. Detailed explanations are available in variables.html.

Base Map

OpenStreetMap is used as the base map to provide geographic context.

Credit: OpenStreetMap

Governorate Boundaries

Geographic boundaries of Tunisia's governorates: Tunisia_shapefiles

Source: IGISMAP

File Description
Tunisia_gov.shp Contains the geographic shapes of the governorates.
Tunisia_gov.shx Contains the spatial index of the Shapefile.
Tunisia_gov.dbf Contains the attribute information associated with the governorates.
Tunisia_gov.prj Contains the coordinate reference system information.

Expected Result

Conclusion

This project provides an interactive geographic platform for exploring Tunisia's governorates and their associated vegetation information.

It establishes the mapping component required for a larger drought monitoring platform and can be further developed by integrating environmental and climatic indicators such as vegetation indices, rainfall, temperature, soil moisture, and other drought-related variables.
